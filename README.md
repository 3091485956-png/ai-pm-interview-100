# AI产品经理面经 · 分类题库精讲（100题背诵手册）

基于《AI 产品经理面经》第二部分「分类题库（附参考答案）」制作的零基础背诵讲解网页。

## 内容

- **6 大类 100 题**全部精讲：技术基础与模型认知（25）、产品设计与需求分析（20）、项目管理与技术协同（15）、商业化与运营策略（15）、伦理合规与高阶思维（15）、行业洞察与开放问题（10）
- 每题七个模块：一句话核心答案 / 零基础白话讲解 / 答案拆解 / 真实案例 / 面试开口模板 / 易错点 / 记忆口诀
- 案例与数据截至 2026 年 9 月

## 功能

- 🎯 背诵模式：隐藏详解自测，点击揭示
- ✅ 已背盖章 + 进度追踪（localStorage 本地保存）
- 🔍 关键词搜索串题
- 📹 内嵌 B 站讲解视频（李宏毅机器学习、RAG、RLHF、A/B 测试）
- 📱 桌面 / 移动端适配

## 使用

直接打开 `index.html` 即可，或访问 GitHub Pages 在线版。

> 模型与监管变化快，面试作答请以最新版本为准。
